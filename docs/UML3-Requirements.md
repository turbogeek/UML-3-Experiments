| UML3-PAT-001 | **patternDefinitions**: UML3 shall represent a pattern definition as an abstract definition whose features are the roles of the pattern, marked by a UML3 keyword that identifies it as a pattern, so that pattern definitions are ordinary model elements that can be specialized, queried, documented and kept in libraries.<br>*Rationale:* SPMS PatternDefinition and UML Collaboration both describe a solution as roles; as a definition with role features, a pattern gets specialization, typing and queries from SysML v2 instead of a separate metamodel.
